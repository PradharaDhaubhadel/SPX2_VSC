# City Mall Website

## Project Description

City Mall Website is a simple and user-friendly website designed to provide visitors with information about a shopping mall and the different services and activities available there. The website brings important information such as shops, events, offers, posters, and details about the mall together in one place.

The main aim of this project is to create a clean, attractive, and easy-to-use website where users can quickly find the information they are looking for. The website uses a consistent design and navigation system across all pages to make it easier for users to move around the website.

## Features

The website includes the following main features:

- Home page with an introduction to City Mall
- Shops page with a directory of available shops
- Search and filter options for finding shops
- Different shop categories such as shoes, fitness, toys, grocery, books, electronics, and beauty
- Events page for displaying mall events
- Offers page for displaying available offers
- Posters page for displaying promotional posters
- About Us page containing information about City Mall and its history
- Contact page for providing contact information
- Consistent navigation across all pages
- Responsive design for different screen sizes

## Technologies Used

The project was developed using:

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Website Pages

### Home
The Home page provides an introduction to City Mall and gives users access to the main sections of the website.

### Shops
The Shops page provides a directory of shops available in the mall. Users can browse shops by category and use the search and filter features to find specific shops.

### Events
The Events page provides information about activities and events taking place at City Mall.

### Offers
The Offers page displays available offers and promotions for visitors.

### Posters
The Posters page is used to display promotional and informational posters related to the mall.

### About Us
The About Us page provides information about City Mall, its background, history, and the role it plays in the community. It also includes statistics about the number of shops, years in the city, shop categories, and visitors.

### Contact
The Contact page provides information that users can use to get in touch with City Mall.

## Design

The website uses a consistent visual style throughout the different pages. A burgundy, cream, and gold color combination is used to give the website a professional and elegant appearance.

The navigation bar is kept consistent across the pages so that users can easily move from one section of the website to another.


## Version Control

Git and GitHub were used to manage the project and keep track of changes made by the group members. Different branches were used to work on individual parts of the project before combining the work together.

## Project Goal

The goal of this project is to create a simple, attractive, and functional City Mall website that provides visitors with useful information while giving them an easy and enjoyable browsing experience.
